# Kantin Kita

Aplikasi katalog menu kantin sekolah berbasis Flutter. Siswa dapat mencari menu,
melihat detail dan total harga berdasarkan porsi, mengelola keranjang, serta
melihat informasi kantin. Katalog dan ilustrasi menu tersedia secara lokal.

## Menjalankan aplikasi

```sh
flutter pub get
flutter run
```

## Build APK Android

```sh
flutter build apk
```

APK hasil build tersedia di `build/app/outputs/flutter-apk/app-release.apk`.
